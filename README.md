# Electronics Product Table

A clean, interactive HTML data table styled with modern CSS features including row hover animations and soft color accents.

## Features

* **Structured Data Presentation:** Displays product inventories, unit costs, quantities, and calculated total sums cleanly using standard HTML tables.
* **Interactive Row Hovering:** Employs CSS `transform: scale()` and color shifts on row hover for improved interactivity and visual focus.
* **Centered Layout:** Uses CSS Flexbox to keep the table properly aligned within the browser viewport.
* **Clean CSS Styling:** Features collapsed borders, custom header background highlights, and clear column cell alignments.
* **Zero Dependencies:** Pure HTML5 and CSS3 with no external frameworks or libraries required.
